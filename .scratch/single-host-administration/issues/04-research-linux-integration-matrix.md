# Research Linux integration matrix

Type: research
Status: open
Blocked by: 01

## Question

Across Ubuntu LTS, Debian stable, Fedora, and RHEL-compatible systems, which stable APIs, D-Bus services, command tools, authorization mechanisms, output formats, and capability checks can safely implement host controls, systemd services, updates, user management, network configuration, firewalls, SELinux, AppArmor, diagnostics, certificate monitoring, and Files operations? Identify gaps requiring bounded command adapters.
